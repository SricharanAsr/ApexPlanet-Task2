# 🤝 Contributing to ApexPlanet-Task2

Thank you for your interest in improving this project! We welcome contributions from everyone.

## 🚀 How to Contribute

1.  **Fork** the repository and clone it locally.
2.  **Create a New Branch** for your changes:
    ```bash
    git checkout -b feature/your-feature-name
    # Or for fixes:
    git checkout -b fix/your-fix-name
    ```
3.  **Implement Your Changes**:
    -   Ensure your code follows the project's style (see `.editorconfig`).
    -   Add meaningful commit messages.
4.  **Verify Your Work**:
    -   Run `make test` to ensure all tests pass.
    -   Run `make run` to verify the analysis pipeline.
5.  **Submit a Pull Request (PR)**:
    -   Provide a clear summary of what your PR accomplishes.
    -   Link any related issues.

---

## 💎 Code Quality Standards

To maintain a high standard of code, please ensure:
-   **Documentation**: All new Python functions must include docstrings (Google or NumPy style).
-   **SQL Quality**: SQL queries should be uppercase where appropriate and include descriptive comments.
-   **Consistency**: Follow PEP 8 guidelines. You can use `flake8` to check for linting errors.
